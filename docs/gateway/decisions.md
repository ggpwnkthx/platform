# Decisions

The decisions behind the gateway contract, each with its evidence. [spec.md](spec.md) is normative for
behaviour; the table format and the rule for contract changes are in
[platform decisions](../platform/decisions.md).

| # | Question | Decision | Stated in | Status | Evidence |

| 1 | Supported runtime versions | Built, tested and released on Bun 1.4.3; the contract says Bun ≥ 1.4.3. Bun 1.2.0 and 1.2.23 lack the early answer, body-producer cancellation, observable upstream handshake refusal and the caller upgrade with gateway headers. | §4 | resolved | [internals.md](internals.md), `test/network/transport.test.ts` |
| 2 | Upload and response commitment boundaries | Observable events are the end of the request stream, the final response headers and the first body byte; peer acceptance is not claimed. | 3 | Refusal of an upstream WebSocket handshake | Distinct from a network failure: the caller gets `502 bad_gateway` without the upstream body, the status is logged and the slot released. | — | resolved | `test/network/transport.test.ts` |
